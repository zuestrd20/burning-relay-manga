# 逆風最後一棒 · Burning Relay

[線上閱讀](https://zuestrd20.github.io/burning-relay-manga/)

十頁繁體中文原創熱血接力漫畫，主角阿澈與凜。故事、角色為原創，漫畫圖像以 AI 生成，非既有作品改編。

## 閱讀方式

每頁格序由右至左。支援單頁、長條、縮圖目錄及頁面文字稿。左方向鍵／向右滑動前進；右方向鍵／向左滑動返回。

## 網站

純靜態 HTML、CSS、JavaScript，無外部相依、追蹤或登入。包含完整十頁 WebP 與縮圖。以 GitHub Pages main 分支根目錄發布。

原始 PNG 母圖另存於交付的 source ZIP，不屬於線上 runtime。素材處理與校驗資訊見 [素材來源](provenance.html) 與 asset-provenance.json。未宣告第三方素材授權，也不暗示 AI 圖像具有特定法律上的獨占權。
